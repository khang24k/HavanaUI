# Modern Monochrome Design Guidelines

## 1. Colors & Accents
- Page Background: `bg-slate-50`
- Surface / Card: `bg-white`
- Primary CTA: `bg-slate-900 text-white hover:bg-slate-800`
- Secondary CTA / Tag: `bg-emerald-50 text-emerald-700 border border-emerald-200`
- Prohibited: Indigo-600, Violet-600, Neon Gradients.

## 2. Component Standards
- Card Padding: `p-6` / `p-8`
- Section Padding: `py-20` / `py-24`
- Border: `border border-slate-200`
- Hover: `transition-all duration-200 hover:border-slate-300 hover:shadow-md hover:-translate-y-0.5`
- Focus Ring: `focus-visible:ring-2 focus-visible:ring-slate-900 focus-visible:ring-offset-2`
